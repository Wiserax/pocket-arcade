# Pocket Arcade

**[Play the collection](https://wiserax.github.io/pocket-arcade/)**

Ten small, independent mobile games: Robot Wreckers, Factory Under Siege, Ricochet Raiders, Monster Diner, Drill Heist, Rescue Harbor, Last Train, Scrap Mech, Tiny Worlds, and Pocket Cleanup.

Touch or mouse. Movement games also support WASD / arrow keys. Each game has saved adventures, replayable stages, a workshop, and daily seeded challenges. Tiny Worlds keeps a gallery of the rooms you make.

Use your browser's **Add to Home Screen** command for a standalone window. The collection works offline after its first successful download. Progress stays in your browser; Settings includes backup export and restore.

No accounts, advertising, energy timers, purchases, or external analytics. Original code-drawn art and buffered instrumental audio. Font licenses are included in `public/fonts/`.

This repository contains the static web distribution. These are experimental small games, not claims of validated retention or commercial performance.

By Alex Wiserax.
